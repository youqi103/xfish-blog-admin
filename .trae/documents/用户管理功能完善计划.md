### 2. 创建密码相关组件（极简复用）

放置于 `src/components/Password/`，仅保留核心功能，适配后端密码校验规则：

#### （1）PasswordModal.tsx（修改密码）

* 核心表单：旧密码、新密码、确认密码（必填 + 一致性校验）
* 关键功能：适配后端密码规则、加载状态、提交回调、关闭重置
* Props 简化：`{ visible: boolean; onCancel: () => void; onSuccess: () => void; userId: number }`

#### （2）ResetPasswordModal.tsx（重置密码）

* 核心功能：二次确认、加载状态、重置成功反馈
* 关键优化：适配后端默认密码生成逻辑，支持一键复制
* Props 简化：`{ visible: boolean; onCancel: () => void; onSuccess: () => void; userId: number }`

### 3. 完善主页面功能（聚焦交互）

在 `src/pages/User/index.tsx` 中快速落地功能，无冗余逻辑：

#### （1）操作列配置

* 操作项：编辑、删除、角色分配、禁用 / 启用、修改密码、重置密码
* 动态渲染：根据用户状态（启用 / 禁用）切换按钮文本，按权限隐藏操作
* 布局：桌面端横向排列，移动端折叠为下拉菜单

#### （2）核心业务逻辑

* 状态管理：`useState`管理 Modal 显隐、表格数据、加载状态
* 接口调用：直接调用封装后的服务层 API，`try-catch`统一错误捕获
* 表格优化：恢复排序（对应后端`created_at/updated_at/last_login_at`）、分页，新增状态 / 角色筛选
* 刷新策略：操作成功后调用`getUserList`刷新表格数据

#### （3）辅助功能

* 密码强度校验：极简工具函数，适配后端密码要求
* 批量操作：可选（基于后端批量接口扩展，无则暂不实现）

### 4. 用户体验优化（关键细节）

* 加载状态：按钮 / Modal 添加加载动画，适配异步接口
* 提示反馈：操作成功 / 失败对应后端`message`提示，自动消失
* 二次确认：删除 / 禁用 / 重置等高风险操作添加确认弹窗
* UI 一致性：严格使用 Ant Design 组件，与现有风格统一

## 三、核心技术要点

1. 接口对齐：请求方式、参数格式、路径严格匹配后端`UserController`
2. 权限适配：前端隐藏无权限操作，适配后端管理员权限校验
3. 错误处理：统一捕获后端异常，展示`message`提示
4. 数据同步：操作成功后自动刷新表格，保证与后端数据一致
5. 组件复用：密码 Modal 抽离，减少页面冗余代码
