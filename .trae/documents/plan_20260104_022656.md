# 博客后台管理系统开发计划

## 项目概述

基于 Ant Design Pro + Umi.js 技术栈，开发四个功能完整的管理页面模块，实现与 RESTful API 的数据交互。

---

## 一、项目结构规划

```
src/
├── pages/
│   ├── Article/              # 文章管理模块
│   │   ├── index.tsx         # 文章列表页
│   │   └── Editor.tsx        # Markdown编辑器
│   ├── Comment/              # 评论管理模块
│   │   ├── index.tsx         # 评论列表页
│   │   └── AuditModal.tsx    # 审核弹窗
│   ├── Statistics/           # 行为统计模块
│   │   └── index.tsx         # 统计仪表盘
│   └── User/                 # 个人管理模块
│       ├── index.tsx         # 用户列表页
│       └── RoleModal.tsx     # 角色权限弹窗
├── services/
│   └── blog-api/             # API服务层
│       ├── article.ts        # 文章相关API
│       ├── comment.ts        # 评论相关API
│       ├── statistics.ts     # 统计相关API
│       └── user.ts           # 用户相关API
└── types/
    └── blog.d.ts             # TypeScript类型定义
```

## 二、API 设计规范（基于 RESTful）

### 2.1 文章管理 API

| 方法   | 路径                    | 功能                             |
| ------ | ----------------------- | -------------------------------- |
| GET    | `/articles`             | 获取文章列表（分页、搜索、筛选） |
| GET    | `/articles/{id}`        | 获取单篇文章详情                 |
| POST   | `/articles`             | 创建新文章                       |
| PUT    | `/articles/{id}`        | 更新文章                         |
| DELETE | `/articles/{id}`        | 删除文章                         |
| PUT    | `/articles/{id}/status` | 更新文章状态                     |

### 2.2 评论管理 API

| 方法   | 路径                    | 功能                       |
| ------ | ----------------------- | -------------------------- |
| GET    | `/comments`             | 获取评论列表（分页、筛选） |
| GET    | `/comments/{id}`        | 获取评论详情               |
| POST   | `/comments`             | 创建评论/回复              |
| PUT    | `/comments/{id}/status` | 审核评论状态               |
| PUT    | `/comments/{id}/report` | 处理举报                   |
| DELETE | `/comments/{id}`        | 删除评论                   |

### 2.3 统计 API

| 方法 | 路径                   | 功能         |
| ---- | ---------------------- | ------------ |
| GET  | `/statistics/visits`   | 访问量统计   |
| GET  | `/statistics/likes`    | 点赞统计     |
| GET  | `/statistics/comments` | 评论统计     |
| GET  | `/statistics/overview` | 综合数据概览 |

### 2.4 用户管理 API

| 方法   | 路径                 | 功能                       |
| ------ | -------------------- | -------------------------- |
| GET    | `/users`             | 获取用户列表（分页、筛选） |
| GET    | `/users/{id}`        | 获取用户详情               |
| POST   | `/users`             | 创建用户                   |
| PUT    | `/users/{id}`        | 更新用户信息               |
| DELETE | `/users/{id}`        | 删除用户                   |
| PUT    | `/users/{id}/role`   | 分配用户角色               |
| GET    | `/users/{id}/logs`   | 用户操作日志               |
| PUT    | `/users/{id}/status` | 账户状态管理               |

## 三、模块详细设计

### 3.1 文章管理模块

**核心功能**:

- ✅ Markdown 编辑器（实时预览）
- ✅ 文章 CRUD
- ✅ 分页/搜索/筛选/排序
- ✅ 状态管理（草稿/发布）
- ✅ 文章分类/标签管理

**UI 组件**:

```
- ProTable（文章列表）
- ModalForm（创建/编辑文章）
- Drawer（文章预览）
- Tag（状态标签）
```

### 3.2 评论管理模块

**核心功能**:

- ✅ 评论 CRUD
- ✅ 审核机制（待审核/已通过/已拒绝）
- ✅ 回复功能
- ✅ 举报处理
- ✅ 多维度筛选

**UI 组件**:

```
- ProTable（评论列表）
- TreeSelect（评论回复层级）
- Tag（状态标签）
- Badge（审核徽章）
```

### 3.3 行为统计模块

**核心功能**:

- ✅ 访问量趋势（日/周/月）
- ✅ 点赞排行
- ✅ 评论活跃度分析
- ✅ 数据可视化

**UI 组件**:

```
- LineChart（访问趋势）
- BarChart（点赞排行）
- PieChart（评论分布）
- Statistic（关键指标）
- Card（数据卡片）
```

### 3.4 个人管理模块

**核心功能**:

- ✅ 用户 CRUD
- ✅ 角色分配
- ✅ 权限设置
- ✅ 操作日志
- ✅ 账户状态管理

**UI 组件**:

```
- ProTable（用户列表）
- ModalForm（用户编辑）
- Select（角色选择）
- Timeline（日志时间线）
- Tag（状态标签）
```
